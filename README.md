**Chronos** is a lightweight task scheduling library inspired by cron. It allows you to schedule and execute Java tasks at specific times, with support for priorities, concurrent execution, and timeout supervision.

### Core Features

- **Task Scheduling:** Schedule tasks for specific execution times.
- **Priority Management:** Order scheduled tasks by execution time and priority.
- **Multithreading:** Execute tasks concurrently using a managed thread pool.
- **Timeout Supervision:** Monitor execution time and interrupt tasks that exceed their configured timeout.
- **Pure Java:** Built using Java's standard libraries, without external scheduling frameworks.

### Purpose

Chronos is a project focused on mastering Java fundamentals, concurrency, thread management, and software architecture by building a reusable scheduling library from scratch.
